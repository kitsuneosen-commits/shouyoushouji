# 加帕里公园：朋友收集（联机版）

基于《兽娘动物园》世界观的朋友收集卡牌游戏，单文件网页版，158 张卡牌全部内置。

## 玩法概要

- 2~8 人对局，房主创建房间，其他人凭 4 位房间码加入
- 抽牌 → 打出角色牌 / 放置 / 凑羁绊 → 反击或连锁反击 → 结算
- 友情值达标后宣告「交够了朋友」，维持一整轮即获胜
- 馒头牌可在结算窗口截断连锁，终结所有反击

## 开始游戏

1. 打开本站（Netlify 部署的页面）
2. 在「游戏服务器」一栏填入 WebSocket 中继服务器地址（`wss://…`，由房主部署，详见游戏内说明）
3. 房主创建房间 → 成员加入 → 开始游戏

## 技术说明

- 前端为单个 `index.html`（内嵌全部卡牌数据与效果引擎），部署于 Netlify
- 联机采用房主权威模式：游戏逻辑全部运行在房主浏览器，服务器只做消息中继
- 对局中掉线的玩家由 AI 自动接管，同一浏览器可凭房间码重连恢复
